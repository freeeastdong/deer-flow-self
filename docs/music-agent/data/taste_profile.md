## 核心偏好

### 最爱的流派（Top 5）
1. 电子/EDM/Trance/House — 运动、开车、高能量场景
2. 氛围/Chill/Lo-fi/Instrumental — 工作专注、深夜放松
3. 后摇/实验电子/Ambient — 深夜独处、情绪沉浸
4. 流行（有质感的）— 日常、旋律向
5. Hip-Hop/R&B/Type Beat — 节奏感、编曲欣赏

### 可接受的流派
- 摇滚（流行摇滚、独立摇滚）
- 民谣（独立民谣、美式民谣）
- 纯器乐/BGM
- City Pop / Synthwave
- 不同语言的音乐（不care语言，编曲好听就行）

### 排斥的流派
- 重金属 / 死亡金属 / 核类
- 宗教 / 福音 / 圣歌类
- 过度商业化的流水线产品（抖音神曲类）

## 特殊偏好

- **歌词态度**：无所谓歌词，编曲/旋律更重要；听外语歌时反而更专注于音乐本身
- **挖掘习惯**：不主动挖掘小众，但听到了觉得好听就会收藏（被动发现型）
- **推荐期待**：希望推荐时给出具体理由（"这首和你常听的XX很像"），而不是泛泛而谈
- **语言态度**：不care语言，中文/英文/日文/俄文都可以，编曲好听就行
- **小众接受度**：能接受实验/小众音乐，但偏好结构清晰、有旋律感的，不喜欢太晦涩的
- **能量曲线**：工作要平静→运动要高能→深夜要安静，需要Agent根据场景精准匹配能量级别
- **社交边界**：聚会时不放歌，Agent不应在此时主动推荐

## 最近一年的变化

- 电子/Beat类占比持续增加（工作场景需求）
- 中文说唱/独立音乐人接触增多
- 对纯器乐/BGM的依赖增加（工作专注需求）
