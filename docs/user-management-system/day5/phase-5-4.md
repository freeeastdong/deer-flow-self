# Phase 5.4 — 更新导航栏入口

## 目标

在导航栏用户下拉菜单中增加"个人资料"入口，点击可进入 `/profile` 页面。

## 涉及文件

- `frontend/src/components/workspace/workspace-nav-menu.tsx`

## 实现内容

### 在下拉菜单中添加"个人资料"选项

在已登录用户的下拉菜单中，**"退出登录"上方**插入"个人资料"链接：

```tsx
<Link href="/profile">
  <DropdownMenuItem>
    <User className="mr-2 h-4 w-4" />
    个人资料
  </DropdownMenuItem>
</Link>
```

菜单顺序：

```
用户名称 / 邮箱
─────────────────
个人资料      ← 新增
退出登录
─────────────────
设置
官方网站
...
```

### 新增导入

```tsx
import { User } from "lucide-react";
```

`Link` 组件已在文件中原有导入。

## 验证

### 验证 1：下拉菜单中出现"个人资料"

1. 登录 DeerFlow
2. 点击左下角头像/设置图标打开下拉菜单
3. **预期结果**：菜单中出现"个人资料"选项（在用户名称下方、退出登录上方）

### 验证 2：点击后跳转到资料页

1. 点击"个人资料"
2. **预期结果**：页面跳转到 `/profile`，显示当前用户信息

### 验证 3：未登录时不显示

1. 未登录状态下查看下拉菜单
2. **预期结果**：只显示"登录"和"注册"，不显示"个人资料"
