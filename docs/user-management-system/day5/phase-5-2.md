# Phase 5.2 — 创建个人资料页面 `/profile`

## 目标

新建页面，展示当前用户的邮箱、昵称、头像（文字占位）。

## 涉及文件

- `frontend/src/app/profile/page.tsx`（新建）

## 实现内容

### 1. 创建页面目录与文件

```bash
mkdir -p frontend/src/app/profile
```

新建 `page.tsx`：

- **客户端组件**：使用 `"use client"`，因为需要调用 `authClient.useSession()`
- **未登录重定向**：如果 `useSession` 返回无用户，自动跳转到 `/login`
- **信息展示**：
  - 头像：用 `name` 或 `email` 首字母作为圆形文字占位
  - 昵称：显示 `nickname` 字段，未设置时显示 `"未设置"`
  - 邮箱：显示 `email`
  - 角色：显示 `"管理员"` 或 `"普通用户"`
- **UI 风格**：与登录/注册页保持一致（居中 Card 布局）
- **返回按钮**：点击返回 `/workspace`

## 验证

### 验证 1：访问 `/profile` 能看到自己的信息

1. 登录 DeerFlow
2. 在浏览器地址栏输入 `http://localhost:2026/profile`
3. **预期结果**：页面显示当前用户的邮箱、昵称（未设置则显示"未设置"）、角色

### 验证 2：未登录时自动重定向

1. 清除 Cookie 或打开无痕窗口
2. 直接访问 `http://localhost:2026/profile`
3. **预期结果**：自动跳转到 `/login` 页面

### 验证 3：返回按钮正常工作

1. 在 `/profile` 页面点击"返回"按钮
2. **预期结果**：跳转到 `/workspace`
